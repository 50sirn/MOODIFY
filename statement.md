# MOODIFY - Project Statement

## Problem Statement
Choosing music that matches a person's current emotional state can be difficult when a large number of songs are available. Traditional genre-based selection does not always capture how a listener feels at a particular moment.

MOODIFY addresses this problem by accepting a user's selected mood, optional natural-language description, preferred language, and genre, and then recommending songs whose emotional profiles are compatible with the user's input.

## Scope
The project focuses on a terminal-based recommendation system implemented entirely in Python. It includes mood selection, keyword-based text analysis, multi-mood detection, emotional compatibility scoring, language and genre filtering, recommendation ranking, and playlist file generation.

The current scope does not include machine-learning models, external AI services, or direct integration with commercial music-streaming APIs.

## Target Users
- Students and learners interested in music recommendation systems
- Users who want quick mood-based song suggestions
- Users who prefer filtering recommendations by language and genre

## High-Level Features
1. Mood selection
2. Optional free-text mood description
3. Multi-mood detection
4. Weighted mood compatibility
5. Language filtering
6. Genre filtering
7. Top-5 recommendation generation
8. Playlist creation
9. CSV-based music storage
10. Input validation and testing
